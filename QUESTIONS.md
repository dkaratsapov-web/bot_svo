# Открытые вопросы к заказчику

Ниже — вопросы из ТЗ (раздел 13) и расхождения/допущения, возникшие при
реализации. До получения ответов действуют варианты «по умолчанию».

## Из ТЗ (раздел 13)

1. **Родство с участником СВО.** Нужен ли отдельный вопрос «кем вы приходитесь
   участнику СВО», если на вопрос об участии выбран ответ «Нет»?
   *Сейчас:* дополнительный вопрос не задаётся.
2. **Сроки ответа.** Бот обещает связаться «в течение 3 рабочих дней»
   (`RESPONSE_SLA_DAYS=3`). Согласовать значение.
3. **Куда направлять уведомления.** Один общий чат операторов или четыре по
   направлениям? Реализованы оба варианта: заданы `ADMIN_CHAT_*_ID` по
   направлениям — используются они, иначе фолбэк на `ADMIN_CHAT_DEFAULT_ID`.
4. **Оператор ПДн и политика 152-ФЗ.** Кто оператор персональных данных и есть
   ли опубликованная ссылка на политику? Нужна для `PRIVACY_POLICY_URL` и
   кнопки «Подробнее» на экране согласия.
5. **Формат выгрузки.** Достаточно ли XLSX или нужна выгрузка в
   Google Sheets / 1С / CRM? Сейчас — XLSX (два листа).

## Допущения и решения по реализации

6. **Формат тикетов.** `ASV-{YYYY}-{000001}` и `CON-{YYYY}-{000001}`; нумерация
   сквозная в пределах года, отдельно по каждому типу. Год берётся по UTC.
7. **Кнопки «Взять в работу»/«Обработано».** Их может нажать любой участник
   чата операторов (проверить принадлежность к чату через API затруднительно).
   Действие и `max_user_id` нажавшего фиксируются в `events`. Если требуется
   ограничить только списком `ADMIN_USER_IDS` — уточните.
8. **Свободный текст для «Индивидуального вопроса».** По ТЗ поле не
   предусмотрено. Реализовано как feature-flag `ASK_FREE_TEXT_FOR_OTHER=false`
   (выключен). Поле `consultations.free_text` в БД присутствует для будущего
   включения.
9. **Ссылка «Связаться с оператором»** (после 3 ошибок ввода) формируется из
   `ORG_SITE_URL` → `tel:` (`ORG_PHONE`) → `mailto:` (`ORG_EMAIL`). Уточните
   предпочтительный канал.
10. **Верификация телефона.** Телефон, полученный кнопкой «Поделиться
    контактом», помечается `phone_verified=true`. Номер извлекается из VCF,
    приходящего от MAX.
11. **Навигация «Назад» на первом шаге.** Для сценария «Вступление» «Назад» с
    шага ФИО возвращает в главное меню; для «Консультации» — к выбору
    направления.
12. **Анти-флуд.** Порог — 20 сообщений/мин на пользователя, далее мягкий
    тротлинг с уведомлением. Значение согласовать при необходимости.
13. **Рассылка `/broadcast`.** Не реализована (по ТЗ). Заложена точка
    расширения (роутер `admin`).
